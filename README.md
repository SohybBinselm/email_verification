# Email Verification App

A Flutter application that implements an email verification flow with password check and dashboard screens.

## Features

- Email verification screen with validation
- Password check screen with visibility toggle
- Dashboard screen with logout functionality
- API integration for email verification and login

## Setup

1. Clone the repository
2. Run `flutter pub get` to install dependencies
3. Add a logo image file named "logo.png" to the assets/images directory
4. Run the application with `flutter run`

## Screens

### Email Verification Screen
- Email input field with validation
- "I didn't have an account" text
- Login button
- API integration for email verification

### Password Check Screen
- Password input field with validation and visibility toggle
- Forget password link
- Login button
- API integration for login

### Dashboard Screen
- Logo
- Welcome text
- Wait text
- Logout button

## API Endpoints

The application uses the following example API endpoints:

- Email verification: `https://example.com/api/verify-email`
- Login: `https://example.com/api/login`

Replace these with your actual API endpoints before deploying the application.
